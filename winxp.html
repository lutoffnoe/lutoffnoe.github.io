Description

J'ai voulu utiliser ce Windows XP afin de découvrir l'expérience des développeur des années début 2000, des systèmes d'exploitations Windows et aussi car un grand nombre de jeux sortis sur Windows XP m'intéressent. Je voulais aussi découvrir l'API Win32.

Mon organisation du travail

J'ai d'abord fais un travail de recherche et de documentation afin de mieux comprendre le système d'exploitation. J'ai ensuite installé Windows XP et le Service Pack 3 (pour le support USB2.0). J'ai ensuite installé des jeux, des drivers, etc. Puis j'ai voulu programmer en utilisant les technologies et logiciels de l'époque.

Mon travail

J'ai donc installé le sytème en parallèle de MS-DOS. Le boot loader de Windows XP prend nativement en charge MS-DOS. J'ai aussi installé certains drivers (USB2.0, Lecteur/graveur CD/DVD, etc). J'ai configurer le système d'exploitation (personnalisation des locales, des comptes, etc). Puis j'ai installé la suite IDE Visual Studio 6.0 avec MSDN(pour la docuementation) afin de programmer des logiciels en C et C++ à l'aide de l'API Win32.
