Description

  • Mettre à jour et interroger une base de données relationnelle

  • Concevoir une base de données relationnelle à partir d'un cahier des charges

Travail réalisé

Afin de stocker des données, on peut utiliser une base de données. Il n'existe un seul modèle utilisable dans tous les cas. La manière dont la base de données est conçue est déterminée en regards à un cahier des charges dépendant du projet. Il est donc indispensable, à chaque projet, de reconcevoir une nouvelle base de données rellationnelle basées sur ce cahier des charges.
Une fois la base de données créée, les données sont stockées coorecctement. Mais cela n'a aucune utilité si nous n'en faisons rien. Il est donc important d'être capable d'interroger la base de données, de visualiser ses données, de pouvoir les modifier, les supprimer ou ajouter de nouvelles données.
