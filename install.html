Installation d'un poste de travail pour le développement

Nombre de personne

1

Durée

1 semaine

Compétences

Administrer des systèmes informatiques communicants complexes

Techniques

Description

Dans le cadre de ce projet j'ai dû installer un système d’exploitation Debian 13 ainsi qu’un environnement de développement informatique (IDE, JDK, etc) sur une machine virtuelle. Il fallait aussi faire une carte mentale afin d’expliquer comment faire cette installation.

Notre organisation du travail

Le travail étant individuel il n’y a pas eu de répartition des tâches. Alors, la seule organisation que j’ai dû faire était le planning, j’ai décidé d’un planning simple, faire chaque tâche les unes à la suite des autres, en faisant chaque tâche le mieux et le plus rapidement possible.

Mon travail

Téléchargement de l’image de la distribution Debian 13, installation de cette distribution Linux via l’installateur graphique fourni, paramètres de base (taille d’écran, focus suit la souris), installation d’un IDE (Jetbrains IntelliJ IDEA), installation de Java et une carte mentale détaillant chaque étape afin de créer un guide d’installation.
