Description

Le projet s’agisait de créer un site web complémentaire par l’entreprise Econocom, site web déstiné aux élèves de troisième à la recherche de stage. Il y a d’abord eu une étude de l’entreprise Econocom, nous avons donc dû récupérer des informations sur Econocom ensuite reformuler ces informations pour des élèves de troisième. Après un de nos « clients » nous a énoncé ses attentes, nous avons fait une maquette en fil de fer puis, avec l’accord du client nous avons développer le site web.

Notre organisation du travail

Pour le wireframe, nous avons séparé le travail par page, chacun à réaliser le wireframe d’un page qui lui été attribuée, ensuite, nous avons chacun codé des éléments qui nous été attribuées.

Mon travail

Je me suis occupé de créer le template pour toutes les pages qui partagent la même ésthétique. Ensuite j’ai utilisé ce template pour la création de deux pages.
